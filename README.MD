# Personal Portfolio Website

A fast, responsive, and minimalistic personal portfolio website showcasing backend development projects, tech stack expertise, and contact information.

**Live Demo:** [https://sadishpanta.com.np](https://sadishpanta.com.np)

---

## 📸 Key Features

* **Light & Dark Theme Toggle:** Custom CSS custom properties and JavaScript state handling for light and dark modes.
* **Responsive Design:** Mobile-first layout using Tailwind CSS flexbox and grid components.
* **Scroll Animations:** Smooth scroll behavior and interactive reveal animations on viewport scroll.
* **SVG & Dynamic Icons:** Modern tech icons integrated via Devicon and Simple Icons libraries.
* **SEO Optimized:** Complete meta descriptions and Open Graph (OG) tags for link previews.

---

## 🛠️ Tech Stack & Dependencies

* **Structure:** [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) with semantic markup
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (loaded via CDN) & Custom CSS variables
* **Fonts:** [Google Fonts](https://fonts.google.com/) (*Fraunces*, *Inter*, *JetBrains Mono*)
* **Icons:** [Devicon CDN](https://devicon.dev/) & [Simple Icons](https://simpleicons.org/)
* **Interactivity:** Native JavaScript (`script.js`) for DOM manipulations and theme persistence
* **Hosting:** GitHub Pages with custom DNS routing via Cloudflare
